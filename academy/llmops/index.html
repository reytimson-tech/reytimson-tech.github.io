By the end of this course you will be able to

  • Explain what changes from prototype to production, and the LLMOps lifecycle
  • Build evaluation suites with code, LLM and human graders, and use them as release gates
  • Layer guardrails on inputs, outputs and actions
  • Choose hosting options and build resilient, fast, scalable deployments
  • Instrument applications with tracing, metrics, alerts and online evaluation
  • Manage versions, model deprecations, safe releases and cost

Who it's for

Developers, ML engineers, platform and SRE teams responsible for running AI applications reliably. Basic Python and some experience of LLM applications are assumed.
