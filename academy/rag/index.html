By the end of this course you will be able to

  • Decide when to use prompting, RAG or fine-tuning
  • Use embeddings and cosine similarity for semantic search
  • Clean, chunk and enrich documents with metadata
  • Improve retrieval with hybrid search, reranking and contextual retrieval
  • Build a grounded RAG pipeline with citations and a refusal path
  • Evaluate retrieval and answers, and run an improvement loop

Who it's for

Developers, data scientists and technical product people who want to build AI assistants that answer from their organisation's documents. You'll need basic Python (see Python for AI).

Draws on documentation and courses from Anthropic, OpenAI, Microsoft, AWS, IBM and Google, including Anthropic's contextual retrieval research. Each module links to free resources for going further. Last reviewed October 2026.
