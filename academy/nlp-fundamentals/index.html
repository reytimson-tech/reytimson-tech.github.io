By the end of this course you will be able to

  • Tokenise and vectorise text with bag of words, n-grams and TF-IDF
  • Build, evaluate and inspect a text classifier
  • Explain embeddings and build simple semantic search with cosine similarity
  • Extract structured data with regex and LLMs — and validate it
  • Compare classic NLP with prompted LLMs and combine them sensibly
  • Discover topics, track trends and handle personal data responsibly

Who it's for

Analysts, developers and aspiring data scientists who know basic Python and pandas and want to work with text. Machine Learning Fundamentals first is recommended.
